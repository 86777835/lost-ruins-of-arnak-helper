# 阿纳克遗迹助手 · 做 / 不做清单（待确认）

调研日期 2026-11-04。完整报告在 `docs/调研/`：BGG 2032 个主题、16285 楼 + 83 个文件页；B 站 290 条热评、贴吧 103 楼、集石短评；应用商店；CGE 官方 16 份 PDF。

## 先说三个事实

- 简中由**一刻馆**出版，官方译名是《阿纳克遗迹》《**探险队长**》《失踪的探险队》（不是"探险领袖"），战役在中文版叫"冒险模式"。站内一律用这套译名，旁边附英文。
- 没找到任何中文的、阿纳克专用的、多人同步的线下工具。专用的只有一个安卓英文单机计分表（Arnak Score，下载 500+）。
- BGG 上排第一的问题是**规则理解**，不是记账：基础版规则区有 27% 的主题在问某张卡怎么用，计分主题只有 8 个。中文玩家提得最多的是扩展和领袖规则（约 12 人），其次是"线下结算总会漏"（约 6 人，单条 94 赞）。

## 要你决定的两件事

**A. 《失踪的探险队》战役（冒险模式）要不要做？** 我建议做最小版。
- 适合做的理由：这是唯一需要跨局保存的部分。6 章分数、剧情点编号、已赢得的卡、失败惩罚目前全靠一张纸记。计分算法是"两人平均分 − 对手分，保留 0.5 分，失败记 −10"，有好几帖问这个。CGE 员工 2024 年说没有计划做 App，官方单人网页 App 不支持这个战役。BGG 规则区一半主题是战役类。
- 不利的地方：只服务单人或双人合作，人少；剧情和章节规则有版权，也怕剧透。
- 最小版内容：建一个战役存档 → 每章记录胜负、难度、领袖、章节分（自动算）、剧情点编号、成就数 → 战役总分自动求和 → 章与章之间的通用提醒（"赢得的卡进常规牌堆""剧情点卡下章放牌库底""失败惩罚见战役书第 X 页"）。
- 不做：剧情文本、章节目标原文、对手 AI、自动判定目标、故事路径地图。

**B. 卡牌问题怎么处理？** 我建议不做完整卡牌词典，在 FAQ 里放一组"易混卡牌"。
- 卡牌问题占 BGG 规则区 27%，需求是真实存在的。
- 但简中基础版规则书是转曲 PDF，没有可以提取的官方中文卡名清单。要做完整词典，要么只能用英文卡名，要么要拿实物卡逐张核对。
- 所以建议的做法是：根据规则书 p22 的"部分卡牌说明"和设计师在 BGG 的裁定，写 20 条左右易混卡牌的说明，用自己的话写，规则助手也能据此回答。

## 不做（留在线下）

| 环节 | 理由 |
|---|---|
| 资源计数、手牌、牌库、抽牌 | 实物一目了然，两边同时记账反而容易对不上；做了就等于做半个数字版 |
| 卡列、月杖、轮次追踪 | 月杖本身就是轮次标记；BGG 检索"忘了第几轮"零命中。只在流程页顺带显示轮次 |
| 研究轨位置、首达奖励归属 | 板上标记很直观，奖励板块拿走就没了；没人抱怨搞错谁先到 |
| 遗址、守护者、神像抽取 | 翻板块的惊喜本身是乐趣 |
| 恩赐用没用过、领袖专属标记 | 实物翻面就表示了状态；大家问的是怎么用，不是记不住 |
| 单人对手 AI 牌堆 | 官方已有网页 App，社区也有 Solo Helper（67 赞） |
| 在线对战、计时器 | 超出范围；BGA 和 CGE 的 Steam 版已经在做在线玩 |
